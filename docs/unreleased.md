# 待发布修改

以下修改累计在主分支，尚未生成新的桌面 Release。当前公开安装包仍为 0.7.21。

- 帮助页以 Folia Plain 的维护与反馈为主体，上游保留为卡片下方的简洁来源链接。
- 窗口标题栏与首页导航留出安全间距；经过导航不再立即唤出窗口按钮，靠近顶边短暂停留才显示。
- 隐藏的窗口按钮不接收鼠标或键盘输入；保留常显设置、窗口拖动与点击穿透解锁入口。
- 网易云、酷狗、QQ 音乐、波点、YouTube Music、Spotify 使用发布者提供的真实应用图标。素材随应用打包，登录窗口、账号切换器与头像角标统一更新，其他扩展平台保留原有回退显示。
- 新增共享玻璃材质：中部模糊、真实背景的局部边缘折射、深浅色明暗保护、细边高光与柔和阴影。已接入底部播放器、首页导航/搜索、网格返回与标题、播放器返回及浮动滑动操作按钮；专辑封面不叠加玻璃。
- 玻璃贴图仅在尺寸稳定后生成，隐藏时关闭折射；支持系统减少透明、增强对比度、强制颜色与减少动态效果，其他浏览器保留基础材质。没有新增持续动画循环或依赖。
