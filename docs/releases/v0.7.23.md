Folia Plain 0.7.23 改善玻璃通透感，支持原版材质切换与 GPU 硬件加速设置，修复播放条跳转，并提供多平台下载。

## 下载

- **Windows 10/11 x64**：`Folia-Plain-Setup-0.7.23-x64.exe` 安装版，或 `Folia-Plain-0.7.23-windows-x64.zip` 免安装版。
- **macOS**：Apple Silicon 选择 `arm64.dmg` / `arm64.zip`，Intel 选择 `x64.dmg` / `x64.zip`。应用未作开发者签名与公证；请参阅[macOS 打开说明](https://github.com/ithtelab/Folia-Plain/blob/main/docs/desktop/macos-app-damaged.md)。
- **Linux x64**：按发行版选择 `.deb`、`.rpm`，或下载 `.tar.gz` 便携包。便携运行说明在 `resources/linux/README-LINUX.txt`。
- **Web 部署**：`Folia-Plain-0.7.23-web.zip` 包含静态网站、部署说明和 Nginx 示例，在线音乐及 AI 功能需要对应后端。不是桌面安装器，不直接双击 HTML 运行。
- `SHA256SUMS.txt` 用于校验附件；`.yml` 与 `.blockmap` 是桌面更新文件。

## 本版变化

- **材质可以切换**：“设置 → 外观 → 玻璃材质”增加液态毛玻璃开关，关闭后恢复原版材质。偏好自动保存，并随外观配置导入导出。
- **更通透的玻璃**：首页歌单卡片使用统一玻璃底层，封面保持清晰。改善浅色模式的通透感，补齐队列拼贴、歌手页等返回键的玻璃材质。
- **播放条只停止流动**：恢复原有模糊、折射和静态高光；静止、悬停、点击、拖动时都不流动，保留进度条操作与平滑边缘。
- **修复播放条跳转**：点击底部播放条的进入播放页区域会直接打开歌词海报，不再受歌单拼贴偏好影响而误入队列。独立队列按钮仍打开队列。
- **GPU 硬件加速**：“设置 → 性能与动效”新增桌面硬件加速开关，默认开启。保存后重启应用生效；遇到黑屏或渲染异常时可以尝试关闭。
- **窗口拖动**：收窄顶部按钮唤出区，移除隐藏按钮的不可拖动占位，顶部左右空白处均可直接拖动，保留导航防误触和窗口按钮。
- **全屏操作**：Esc 可退出桌面窗口全屏；有弹窗时先关闭弹窗。全屏中鼠标静止约 3 秒后自动隐藏，移动、点击或按键后立即恢复，菜单和拖动操作期间保持可见，退出全屏后恢复正常指针。
- **会员识别**：网易云账号面板区分 VIP / SVIP，显示接口返回的会员等级、到期日期，优先使用对应产品的官方会员标识；右下角平台入口同步显示会员标记。已过期会明确标注，日期缺失时显示“到期日期暂不可用”，图标加载失败时保留文字标识。音质保持原有标准、极高、无损与 Hi-Res，并按接口实际返回的档位记录音源。
- **多平台附件**：本项目提供 Windows、macOS、Linux 桌面包和 Web 部署包，来源与校验文件统一；不再把源码构建方式写成现成下载。

更新检查继续使用本仓库 `ithtelab/Folia-Plain`，保留 GitHub 直连与第三方国内加速入口。macOS 和 Linux 包通过各自系统的云端构建与打包资源检查，尚未完成每种发行版及设备上的人工运行验证；Intel Mac 的 Spotify 原生播放受上游二进制支持限制。

桌面安装包包含音频处理程序、分析运行库及模型，体积较大。在线音乐与 AI 仍需按平台要求配置或登录。问题请反馈到[本项目仓库](https://github.com/ithtelab/Folia-Plain/issues)；上游项目：[folia-major](https://github.com/chthollyphile/folia-major)。
