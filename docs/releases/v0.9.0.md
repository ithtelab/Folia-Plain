Folia Plain 0.9.0 把「播放全部」拆出一半随机播放，洗牌可以按轮不重复，拼贴歌单点歌不再黑屏，本地大曲库导入后也不再卡。

## 下载

- **Windows 10/11 x64**：`Folia-Plain-Setup-0.9.0-x64.exe` 安装版，或 `Folia-Plain-0.9.0-windows-x64.zip` 免安装版。
- **macOS**：Apple Silicon 选择 `arm64.dmg` / `arm64.zip`，Intel 选择 `x64.dmg` / `x64.zip`。应用未作开发者签名与公证；请参阅[macOS 打开说明](https://github.com/ithtelab/Folia-Plain/blob/main/docs/desktop/macos-app-damaged.md)。
- **Linux x64**：按发行版选择 `.deb`、`.rpm`，或下载 `.tar.gz` 便携包。便携运行说明在 `resources/linux/README-LINUX.txt`。
- **Web 部署**：`Folia-Plain-0.9.0-web.zip` 包含静态网站、部署说明和 Nginx 示例，在线音乐及 AI 功能需要对应后端。不是桌面安装器，不直接双击 HTML 运行。
- `SHA256SUMS.txt` 用于校验附件；`.yml` 与 `.blockmap` 是桌面更新文件。

## 本版变化

- **随机播放，和一轮不重复**：「播放全部」拆成两半，左边按顺序播，右边把同一批歌随机播。合集页、歌手页、专辑海报和歌手海报都有这一对，可以随机整个合集或某位歌手的全部热门。新增设置项「一轮不重复」（设置 → 播放控制，命令面板也能切）：打乱时把这一轮听过的排到没听过的后面，同一批歌再随机就接着上一轮；列表循环下听完整轮会自己静默重洗，当前这首不会被掐断。只跟踪按轮洗出来的队列，按顺序播的专辑不受影响。
- **信息条动作一点就到**：集合页与歌手页的信息条上排一行「播放全部｜随机、加入队列」，下面一排图标动作格：收藏星标和列表固定，其余按优先级补位——加入歌单、收进速记簿、改名、设置封面、重新导入 / 重新拉取、实体信息、导出、整理。放不下的连同删除、折叠信息条一起留在「⋯」。首页本地那组也有了单独一行（目录、导入文件夹、刷新、导入歌单文件），窄缝和窄窗口下逐行退让。进行中的动作把图标换成转圈的加载状态。
- **本地大曲库导入不再卡**：导入后补元数据，原来每 25 首就把 `local_music`、实体、归属三张表整表读一遍，每批还在读写事务里跑在主线程上。曲库一万首时后半程每批要 2–3.5 秒，四百批合计十几到二十多分钟，期间别的读都排队。现在先按这一批的名字和文件夹索引预取要用的数据，再在内存里同步跑原来那套规则，只写这一批。数据库升到 version 1，新增 `albumContextKey` 派生字段并建索引，**更新后第一次启动会把已有歌曲迁移一次**。
- **拼贴歌单能进播放页了**：歌单打开方式设成「拼贴」时，点歌会黑屏。原因是拼贴墙把展开卡片的控制条写死成需要播放 Provider 的那一套，而拼贴视图不挂这个 Provider —— 它的歌只是浏览用。现在拼贴显示自己的播放与加入队列按钮。
- **几处细节**：返回键和右下角面板引导在场景（影厅）里固定画在整页左上角，不再跟着歌词样式贴到银幕上；从托盘恢复主窗口、最小化时，任务栏缩略图上的播放按钮都会照常更新。

## 已知情况

- 一轮不重复只在「按轮洗出来的队列仍是洗出来顺序」时跟踪，手动拖动排序或按顺序播放会退出这一轮。
- 拼贴视图的随机播放走的是「播放全部」的随机版本；拼贴本身是浏览用的，不会把自己当成播放队列。
