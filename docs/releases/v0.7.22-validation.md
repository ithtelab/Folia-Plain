# Folia Plain 0.7.22 发布验证记录

## 2026-10-22 补充修改与核对

- 更新界面移除上游网盘和 AUR；只读取 `ithtelab/Folia-Plain` 的稳定版。继承的滚动通道选择按稳定版处理，已发布存储键不变。
- 自动更新由本项目 GitHub API 确认版本、元数据摘要，再验证下载信息和安装包摘要；第三方 GH-Proxy 优先，失败或摘要不符时重试 GitHub。合并重复下载请求，禁止降级与 Web 安装器。镜像仅接受本仓库发布附件地址。
- 隔离的真实 Windows Electron 更新器模拟 0.7.21，成功下载本仓库 0.7.22 安装包（247,403,992 字节），与正式元数据 SHA-512 一致；没有执行安装器。该项验证的是补充修改前已发布的 0.7.22 附件，重新打包后另核对新附件。
- 底部播放器关闭流动、指针折射形变与按压形变；常态、悬停、按住均验证无流动 Canvas、滤镜位移不变。导航仍可缓慢流动。
- 共享折射贴图提高至最多两倍采样，软化边界覆盖；流动层提高小尺寸采样，保留既有像素预算。核对 100%、125%、200% 像素比及缩小显示的导航、搜索、返回、歌曲卡片和播放条圆角。
- 亮色材质减轻白色填充并保留深背景文字保护。真实 Chrome 24 组深浅配色/黑白条纹背景下，小字最低对比度约 4.75:1；360 像素窗口进度操作、长时长文字核对通过。
- “主页与歌单”新增歌单打开方式：默认封面网格，可选队列同款拼贴，仅用于网格资料库中的歌单，专辑不变。偏好持久化并接入命令面板；资源、搜索、播放范围与集合动作仍沿用现有逻辑，重复歌曲保留独立条目。
- 在真实集合适配器中核对拼贴搜索、播放筛选结果、单曲入队、切回网格和专辑不受影响，浏览前后播放队列一致；定位可清除筛选并展开目标海报。拼贴不注册或覆盖队列墙面的转场 peer。
- 类型检查、相关 1,160 项单元检查、既有 35 项播放器/歌曲卡片/顶栏浏览器检查通过。完整检查及最终 Windows 包以同一提交的云端构建记录为准。

以下为首次 v0.7.22 的累计记录；流动策略以本节和当前更新说明为准。

记录 v0.7.21 之后、v0.7.22 打包前的累计修改及验证。面向用户的更新说明见 [v0.7.22.md](v0.7.22.md)。

- 帮助页以 Folia Plain 的维护与反馈为主体，上游保留为卡片下方的简洁来源链接。
- 窗口标题栏与首页导航留出安全间距；经过导航不再立即唤出窗口按钮，靠近顶边短暂停留才显示。
- 隐藏的窗口按钮不接收鼠标或键盘输入；保留常显设置、窗口拖动与点击穿透解锁入口。
- 网易云、酷狗、QQ 音乐、波点、YouTube Music、Spotify 使用发布者提供的真实应用图标。素材随应用打包，登录窗口、账号切换器与头像角标统一更新，其他扩展平台保留原有回退显示。
- 新增共享玻璃材质：中部模糊、真实背景的局部边缘折射、深浅色明暗保护、细边高光与柔和阴影。已接入底部播放器、首页导航/搜索、网格返回与标题、播放器返回及浮动滑动操作按钮；专辑封面不叠加玻璃。
- 玻璃贴图仅在尺寸稳定后生成，隐藏时关闭折射；支持系统减少透明、增强对比度、强制颜色与减少动态效果，其他浏览器保留基础材质。没有新增依赖，流动层仅在对应区域可见、允许动效时运行。
- 修复同一浏览器用过正式 PWA 后，开发预览可能持续显示旧离线页面的问题：开发服务为旧 `/sw.js` 提供更新交接，普通刷新即可回到当前页面，不删除账号、音乐或缓存数据。
- 首页的整页模糊移到独立背景层，保留背景外观并让导航/搜索正确采样；浅色玻璃减少白色填充，增加细边明暗层次。
- 玻璃补齐交互时的流动感：光泽与边缘折射跟随指针，按压压缩、松开回弹，页签选择胶囊伸展收束，尺寸变化时材质有短促弹性过渡。只变形装饰层，文字和命中区域保持稳定；接入现有“降低 UI 微动效”偏好，停下后停止逐帧更新。
- 按提供的液态金属按钮参考增加流动反射带，复用现有 Paper shader：导航与播放器缓慢常态流动，搜索/返回/标题/滑动按钮仅悬停或聚焦时流动，按压加快。反光采用细边和实时背景柔光融合，避免浅色页面出现固定粗黑边；隐藏、降低动效/透明度时停用，并释放 GPU 资源。
- 右下角平台切换入口保留真实 App 图标，将图标从 40 调整为 28 像素、保留 40 像素点击区域；玻璃胶囊统一留白，缩短分隔线、减轻箭头。登录窗口和头像落点仍以实际图标边界定位。
- 底部歌曲卡片和面板按钮统一使用播放条同款玻璃：播放条常态慢流，卡片和面板按钮只在交互时流动。混音时卡片保留进度描边并暂停装饰反光；面板开关和左滑命令维持原行为。
- 修复流动反光打开后背景模糊失效的问题：取消 WebGL 层的 CSS 混合模式，改为着色器输出透明高光，让模糊、折射和流动同时生效，深浅背景均不再叠固定黑边。
- 提高底部辅助文字的可读性：歌曲卡片的状态文字和歌手名更清晰、行间留白增加；播放时间放大为 11 像素，采用主题主文字颜色并给长时长保留伸展空间。卡片和面板按钮减轻阴影，播放条保留主要视觉重量，不增加玻璃填充或持续计算。
- 搜索框聚焦时改用贴合玻璃边缘的细亮线，去掉粗黑色外轮廓；高对比度和强制颜色模式保留清晰的系统色焦点提示。深浅外观、输入及焦点回退核对通过。
- 接入维护者提供的 Folia Plain v2 应用图标：PNG 用于桌面、网页/PWA 与应用内介绍，Windows 打包改用原始多尺寸 ICO；配套 SVG 用于可缩放图标，并导出新的 macOS 单色托盘素材。原始设计文件保留在本地 `图标/`，规范素材路径见 `build/iconAssets.md`；随 0.7.22 统一打包。
- 首页登录入口改用共享毛玻璃材质，保留真实平台图标，平时静态、交互时流动；首次登录仍先选择平台，登录失效时仍直接打开对应平台。
