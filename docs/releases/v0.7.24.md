Folia Plain 0.7.24 让新装用户直接从网格开始，首次引导可以跳过，并继续打磨液态玻璃、卡片交互与播放流畅度。

## 下载

- **Windows 10/11 x64**：`Folia-Plain-Setup-0.7.24-x64.exe` 安装版，或 `Folia-Plain-0.7.24-windows-x64.zip` 免安装版。
- **macOS**：Apple Silicon 选择 `arm64.dmg` / `arm64.zip`，Intel 选择 `x64.dmg` / `x64.zip`。应用未作开发者签名与公证；请参阅[macOS 打开说明](https://github.com/ithtelab/Folia-Plain/blob/main/docs/desktop/macos-app-damaged.md)。
- **Linux x64**：按发行版选择 `.deb`、`.rpm`，或下载 `.tar.gz` 便携包。便携运行说明在 `resources/linux/README-LINUX.txt`。
- **Web 部署**：`Folia-Plain-0.7.24-web.zip` 包含静态网站、部署说明和 Nginx 示例，在线音乐及 AI 功能需要对应后端。不是桌面安装器，不直接双击 HTML 运行。
- `SHA256SUMS.txt` 用于校验附件；`.yml` 与 `.blockmap` 是桌面更新文件。

## 本版变化

- **新装默认就是网格**：第一次打开看到的资料库界面从拼贴墙改为网格，和首启引导里默认选中的那一项一致。想换回拼贴墙随时可以在“设置 → 通用 → 资料库界面”或命令面板里切换。
- **首次引导可以跳过**：认识思索模式的引导页新增“我是老手，自己逛”入口，不想看教程的人不必先完成一次页面思索。跳过同样记作已看过，不影响后续版本的说明；想再看一次可从设置或帮助重新进入。
- **更薄更一致的玻璃**：卡片与控件的模糊、边缘高光和薄膜统一到同一套参数，整体减薄后能透过玻璃看清背后的画面。亮色模式补上压暗的色调曲线和上亮下暗的边缘，不再因为没有对比而显得没有玻璃感。
- **卡片按压液波**：按住歌单卡片时，两道不规则、边缘模糊的液波从按下的位置向外扩散，越过卡片边缘后消失；只改装饰层，点击、拖动和文字位置都不受影响。
- **歌词页返回更柔和**：从歌词页返回首页的淡入不再受主线程卡顿影响，首页不会先空一帧再突然出现；返回途中卡片的飞入描边改用与玻璃一致的高光，不再出现深色细线。
- **卡片边缘不再有黑线**：悬停、按下和转场飞行时的卡片只保留玻璃自身的亮色边缘，去掉了回落到文字色而形成的深色描边。
- **齿轮时间线也用上玻璃**：歌词时间轴校准窗口改用与设置、通用弹窗相同的液态玻璃材质，不再是自己写死的半实底色。
- **播放更省电**：进度条改为合成层动画，歌词整屏呼吸浮动改为 CSS 动画，玻璃镜片的法线图按尺寸共享并异步编码，播放期间的每帧主线程工作明显减少，打开侧面板也更轻快。
- **材质可以切换**：“设置 → 外观 → 玻璃材质”的液态毛玻璃开关，关闭后恢复原版材质；偏好自动保存并随外观配置导入导出。
- **播放条直达歌词海报**：点击底部播放条进入歌词页，队列按钮与歌单偏好各自保留。Esc 可退出窗口全屏；全屏中鼠标静止约 3 秒后隐藏，操作后立即恢复。
- **GPU 硬件加速**：“设置 → 性能与动效”新增桌面硬件加速开关，默认开启，保存后重启生效。
- **会员识别**：网易云账号面板区分 VIP / SVIP，显示接口返回的等级、到期日期和官方会员标识；已过期会明确标注，日期缺失时不猜测。

更新检查继续使用本仓库 `ithtelab/Folia-Plain`，保留 GitHub 直连与第三方国内加速入口。macOS 和 Linux 包通过各自系统的云端构建与打包资源检查，尚未完成每种发行版及设备上的人工运行验证；Intel Mac 的 Spotify 原生播放受上游二进制支持限制。

桌面安装包包含音频处理程序、分析运行库及模型，体积较大。在线音乐与 AI 仍需按平台要求配置或登录。问题请反馈到[本项目仓库](https://github.com/ithtelab/Folia-Plain/issues)；上游项目：[folia-major](https://github.com/chthollyphile/folia-major)。
