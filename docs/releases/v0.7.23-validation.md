# Folia Plain 0.7.23 发布验证记录

0.7.22 的累计修改已纳入[版本说明](releases/v0.7.22.md)，打包前的检查记录保存在[验证记录](releases/v0.7.22-validation.md)。

记录 v0.7.22 之后的修复。用户于 2026-10-22 确认发布 v0.7.23，范围扩展为 Windows、macOS、Linux 和 Web；Docker 版本仍为 1.2.0，未发布容器镜像。

## 本轮修改与原始反馈

### 底部播放器入口跳转错误（2026-10-22）

- 状态：已修复，完成跳转绑定回归测试。
- 版本：v0.7.22。
- 操作：在歌单页点击底部播放条的进入播放页区域（反馈截图一）。
- 预期：直接进入全屏歌词海报页面（反馈截图二）。
- 实际：进入播放队列拼贴页面（反馈截图三）。
- 根因：播放横条复用了跟随播放入口偏好的跳转回调，偏好为拼贴时进入队列。现改为明确进入播放器，保留歌单播放入口偏好、播放/暂停、进度拖动和队列按钮各自的操作行为。

### 队列拼贴返回键未使用统一毛玻璃（2026-10-22）

- 状态：已接入统一玻璃材质，同时补齐歌手页返回键。共用返回控件覆盖队列拼贴与 bravais，核对歌单、目录和歌词页既有接入；保留原返回行为与隐藏热区。
- 版本：v0.7.22。
- 现象：队列拼贴页面左上角的圆形返回键仍是普通半透明底色，没有本项目统一的毛玻璃效果（本次反馈截图）。
- 预期：返回键使用统一毛玻璃材质，保留原有返回行为和点击区域。
- 同类排查：检查其他页面的返回键及类似的悬浮导航控件，记录遗漏并一并修复；核对亮色、暗色、不同背景及缩放后的边缘表现，同时保留减少透明度等既有回退。

### 播放横条停止流动后丢失原有玻璃质感（2026-10-22）

- 状态：已恢复原反光层的固定帧，保留背景模糊、边缘折射和高光；不再监听播放条的材质交互，不启动流动时钟。
- 版本：v0.7.22。
- 原始现象：底部播放横条的材质与现有统一毛玻璃不一致，通透感下降（本次反馈截图）。先前关闭整个反光层使质感改变，本轮仅冻结该层。
- 用户明确要求：保留原来的玻璃样式与通透质感，只停止流动；常态、鼠标悬停、点击及拖动操作时都不流动。
- 修复目标：恢复原有的背景透出、模糊、边缘折射和静态高光，保持与其他玻璃控件一致的材质；保留圆角边缘平滑修复，文字、按钮与进度操作维持原有行为。
- 验收：在相同背景、主题与尺寸下对照停止流动前的效果，确认仅装饰动画停止，玻璃质感保留。

### 歌单卡片接入现有毛玻璃材质（2026-10-22）

- 状态：已实现，移除卡片原有不透明底层对玻璃的遮挡。仅焦点卡片保留一个固定反光画布，其余卡片不创建反光画布，避免随卡片数量增加 GPU 上下文。
- 范围：首页歌单卡片的容器与文字信息底层（本次反馈截图一，包括喜欢的音乐、云盘等卡片）。
- 预期：使用本项目现有统一毛玻璃材质，体现背景透出、模糊、边缘折射和静态高光，深浅模式均保持通透感。
- 保留封面原图、卡片布局与点击行为；玻璃作用于卡片底层，封面和文字保持清晰。

### 浅色模式玻璃与参考效果图不一致、不通透（2026-10-22）

- 状态：已调整浅色背景色阶压缩，减少普通背景的过度泛白；保留极暗背景下的小字可读性。共用材质同步覆盖导航、搜索、播放条和新接入的歌单卡片。
- 版本：v0.7.22。
- 现象：浅色模式导航胶囊等玻璃控件看起来偏实色，通透感与此前提供的效果图不一致（本次反馈截图二）。
- 修复目标：以此前效果图和用户认可的现有材质为参照，恢复真实背景透出及玻璃层次；检查导航、搜索、播放横条、歌单卡片及其他共用材质的控件。
- 验收：在相同背景、主题、尺寸下对照实际应用与效果图，核对静止、悬停及缩放状态；同时保持文字可读、圆角平滑。播放横条始终遵守上述“只停止流动、保留玻璃质感”的要求。

### 毛玻璃与原项目效果切换（2026-10-22）

- 状态：已实现，位于“设置 → 外观 → 玻璃材质”。接入持久化、外观配置导入导出及命令面板。
- 设置中增加“液态毛玻璃”开关，默认保留当前选择的液态毛玻璃效果；关闭时切回原项目的界面材质。
- 原项目效果需要保留完整回退，关闭开关后应呈现原来的材质，而非仅移除模糊或改为纯色底。
- 统一覆盖已接入及待接入的导航、搜索、播放器、返回键、歌单卡片等控件，保留布局和操作行为。
- 开关持久化并接入外观配置导入导出；毛玻璃启用时，播放横条仍保留玻璃质感且在所有交互状态下不流动。

### GPU 硬件加速开关（2026-10-22）

- 状态：已实现，位于桌面版“设置 → 性能与动效”。接入主进程启动配置、保存确认、重启提示及桌面命令面板。
- 位置：“设置 → 性能与动效”，新增“GPU 硬件加速”开关，默认开启，用户可以关闭。
- 用于桌面客户端的硬件加速偏好，持久化并在应用启动时生效；切换后提示需要重启应用。
- 实现时核对现有图形模式与硬件加速控制路径，确保界面选项与实际启动行为一致；按功能设置接入命令面板。
- 用户提供的截图仅作为开关样式与说明方式的参考。

## 本地验证（2026-10-22）

- 探索页底部补入 80 像素内容渐隐与 96 像素末尾留白，使用原有组件探针核对浅色和深色模式，封面柔和融入共享背景，未给播放条叠加实色遮罩。
- 右侧播放面板、设置窗口、通用弹窗、下拉菜单、侧栏与筛选胶囊统一接入共享玻璃表面；浏览器实测开启时透出真实背景，关闭后恢复原版实色材质。播放器底部布局 21 项、探索页 18 项、玻璃光学与弹簧 10 项检查通过。
- 歌单卡片不再从背景色过渡到玻璃，顶栏选中层改为 8% 轻灰；探索拼贴的返回与刷新恢复圆形玻璃并保持间隔。拼贴墙面 30 项手势与播放控件检查通过，新增从拼贴页点击播放条进入歌词页的回归用例。
- 顶栏选中文字已跟随主题：暗色为白色、亮色为黑色，明暗两套实际渲染检查通过。
- 所有 `theme-polaroid-card` 容器在液态玻璃开启时统一取消白色填充和背景过渡，覆盖首页、歌单、目录与转场临时卡片；启用 Service Worker 的实际浏览器环境确认计算背景为完全透明。
- 亮色玻璃取消常规和首次挂载 `frost` 阶段的全部填充，折射色调曲线改为中性；切换歌单/电台时新卡片不再先闪 74% 白色。
- 本地开发环境不再注册 PWA Service Worker，并在启动时注销旧 worker、清理 Workbox 缓存；切换歌单到电台后遍历 5 个可见亮色玻璃层，计算填充均为 `rgba(0, 0, 0, 0)`。
- 开发者页的会话日志面板接入共享玻璃层；探索页只保留 80 像素内容淡出和 96 像素末尾滚动空间，额外雾气层已移除。底部播放条保持原有样式、模糊强度和静止状态不变。
- 玻璃减薄与对齐（2026-10-22）：背景模糊从 14px 降到 6px、饱和度 1.35 → 1.15，镜头中心雾化 7px → 3.5px；控制类填充按控件分级（导航/搜索/按钮 0.11、播放条 0.22、窗口 0.42），`data-glass-legacy` 在正常玻璃路径也输出，控件不再统一套用窗口的实底。条纹背景探针在明暗两套下确认导航与搜索可透出背后条纹，标签文字仍清晰。
- 亮色玻璃可见度：色调曲线改为向下压缩 `0 0.2 0.44 0.72 1`，边缘改为上亮下暗（外圈 0.55、顶光 0.9、底部 `rgb(64 62 74 / 0.16)`），填充改为薄冷灰膜；镜头位移亮色 22 / 暗色 16，并作为基准值传入 `useLiquidGlassMotion`，避免每帧被覆盖。条纹探针对比：亮色面板内部对比跨度 214、暗色 212，两套观感接近。
- 卡片与控件材质统一：`liquid-glass-card` 与 `liquid-glass-content-card` 使用同一模糊（6px/1.15）、同一套上亮下暗边缘与薄膜（浅 0.08 / 深 0.12）；四类卡片补充 `data-card-tone` 标记以切换明暗边缘。实测首页卡片 `--glass-tint` 为 `rgb(252 251 249 / 0.08)`、rim 为 `rgba(255, 255, 255, 0.55)`，与导航一致。
- 卡片按压液波：新增 `GlassPressRipple` 与 `resolvePressOrigin`，波环从指针落点（百分比定位、边缘夹取）向外扩散，只改装饰层，不进入 React 渲染；已接入首页歌单卡、库卡片与目录卡，减少动态效果或关闭玻璃时不显示。落点换算 3 项单测通过。
- 卡片深色描边清理：`theme-polaroid-card` 的边框在所有交互状态固定为透明，玻璃边缘只由光学 rim 与投影绘制；转场飞行描边 `morphProbes.frameOf` 在玻璃开启时改用白色高光 `rgb(255 255 255 / 0.62)`，不再使用会显示为深色细线的 `--text-primary`。实测飞行期间 box-shadow 为白色内描边，卡片 frame 边框为 `rgba(0, 0, 0, 0)`。
- 歌词页返回首页的闪动：逐帧采样发现切回首页那一帧主线程卡顿约 104ms，framer 的 JS 淡入从 0.11 跳到 0.87。首页层改为 CSS 过渡（`home-reveal-layer`），并新增 `useHomeReveal` 等两帧绘制后再启动淡入；`setView('home')` 同一次写入里解除 `isHomeFullyHidden`。录屏逐帧确认卡片像素从 198 平滑过渡到 239，约 20 帧无跳变。
- 播放性能：进度条填充从每帧写 `clip-path` 改为 `scaleX`（合成层，实测该处的样式重算与绘制开销消失）；classic 歌词整屏呼吸浮动从 framer 无限循环改为 CSS 动画 `classicVisualizer.css`；玻璃镜片图改为按几何尺寸共享并异步 `toBlob` 编码（`glassLensImages` + `lensImageCache`，引用计数，容量 64），打开侧面板时不再每块同步 `toDataURL`。镜片缓存 4 项、音频流 2 项单测通过。
- 流畅度复核（2026-10-22，生产构建）：首页空闲 p95 8.3ms、零长帧；播放页（classic 歌词 + 进度条运行）p95 4.4ms、零长帧；卡片按压确认两个波环从指针位置起始并逐帧改变 transform；歌词呼吸浮动确认为运行中的 CSS 动画；进度条逐帧改变 `scaleX` 且 `clip-path` 已移除；7 个玻璃表面的定位、圆角与层级正确，装饰层未拦截点击。组件测试 833 项通过，关键 UI 截图串行运行 4 项通过。
- 首次启动默认与引导：初始资料库界面从 bravais 改为 grid（`LIBRARY_SUITE_INITIAL_CHOICE_FALLBACK`），构建变量仍可覆盖；全新 profile 实测首启引导第一页的网格卡片为选中态（`aria-pressed=true`），写入 `library_suite=grid`。思索引导页新增跳过入口，实测文案、点击关闭与写入 `folia_last_seen_ponder_onboarding_version=0.7.23` 均正常，跳过不会遮挡后续版本的发布说明。`library`、`i18n`、`app` 共 1148 项单测通过。
- 发布准备期间补入窗口拖拽修复：整条顶部 16 像素不再是不可拖动唤出区域，只有右上角按钮区需要触发；隐藏按钮也不再留下原生不可拖动占位。4 项顶栏浏览器测试通过，隔离 Electron 窗口用系统鼠标分别从左、中、右空白与隐藏按钮区域拖动，四处均实际移动窗口，并确认右上角唤出可用。
- 全屏修复：此前播放交互只查看 `document.fullscreenElement`，没有覆盖 Electron 原生窗口全屏。新增独立全屏会话，订阅原生与网页全屏，Esc 在弹窗之后优先退出全屏；使用可信主窗口限定的显式退出 IPC，重复退出不会反向进入。全屏闲置 3 秒隐藏指针，操作、拖动、菜单、失焦与退出时恢复，单一计时器且不在鼠标移动时更新 React state。7 项逻辑测试、4 项顶栏回归和隔离 Windows Electron 的完整 Esc/弹窗/鼠标恢复验证通过。
- 补入会员识别：使用钉死的 API 4.41.1 的 `vip/info/v2`，VIP 响应字段对照 `chaunsin/netease-cloud-music/api/weapi/vip.go` 的接口结构。按实际有效的产品区分 VIP / SVIP，显示等级与到期日期；官方标识采用对应产品的 `iconUrl`，仅接受平台图片域名并升级为 HTTPS，加载失败回退到文字。会员读取失败不使有效登录失效，未知日期不编造。
- 最终范围按用户确认撤回本轮新增的高清臻音、母带与环绕选项及兼容音源请求，不宣传官方空间解码、多声道直通或位完美输出。保留标准、极高、无损与 Hi-Res，修正 Hi-Res 请求返回较低档位时的内部实际音质记录。深浅色会员展示、已过期和未知日期使用显式样本核对，不把样本日期当作真实账号结果。

- 类型检查通过；设置、存储、命令注册、GPU 启动与播放条跳转相关 323 项单元测试通过；播放条、底部布局、正在播放卡片与顶栏相关 35 项浏览器组件测试通过。
- 使用隔离桌面配置验证三次真实启动：默认硬件加速开启，保存关闭后当前进程不变，重启关闭生效，再次开启后重启恢复。未改动用户日常配置。
- 实际浏览器核对深浅色歌单卡片、共用返回键、原版材质回退及刷新后偏好保留，关闭时反光画布和折射层均卸载。
- 播放条在 DPR 1、1.25、2 以及 80%/100% 缩放下核对边缘；静止、悬停和按压时反光帧、折射参数保持不变。深浅主题与极端背景下 24 组小字对比检查通过，最低 4.75:1。
- 验证产物保存在本地 `.codex-tmp/glass-material-validation/`、`.codex-tmp/glass-edge-validation/`、`.codex-tmp/bottom-readability/` 和 `release/gpu-native-validation/`，这些目录不纳入发布源码。
