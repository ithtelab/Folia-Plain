Folia Plain 0.8.1 把上游 0.7.28 的内容真正接了进来：新歌词样式、影厅场景、窗口按钮位置，并修好了液态玻璃、平台图标和启动引导。

## 下载

- **Windows 10/11 x64**：`Folia-Plain-Setup-0.8.1-x64.exe` 安装版，或 `Folia-Plain-0.8.1-windows-x64.zip` 免安装版。
- **macOS**：Apple Silicon 选择 `arm64.dmg` / `arm64.zip`，Intel 选择 `x64.dmg` / `x64.zip`。应用未作开发者签名与公证；请参阅[macOS 打开说明](https://github.com/ithtelab/Folia-Plain/blob/main/docs/desktop/macos-app-damaged.md)。
- **Linux x64**：按发行版选择 `.deb`、`.rpm`，或下载 `.tar.gz` 便携包。便携运行说明在 `resources/linux/README-LINUX.txt`。
- **Web 部署**：`Folia-Plain-0.8.1-web.zip` 包含静态网站、部署说明和 Nginx 示例，在线音乐及 AI 功能需要对应后端。不是桌面安装器，不直接双击 HTML 运行。
- `SHA256SUMS.txt` 用于校验附件；`.yml` 与 `.blockmap` 是桌面更新文件。

## 本版变化

- **影厅场景（Beta）**：播放页可以变成一座影厅，你的歌词样式与背景放在荧幕上，可以拖动转头看四周；桌面版还能开「声线追踪」，让音乐听起来像在厅里。返回键固定在整页左上角，不再跟着歌词样式跑到银幕上。
- **新的应用图标与平台标识**：应用图标换成四块积木拼成的 F。九个音乐平台统一使用各自的真实应用图标，登录按钮、平台切换器和账号页保持一致。
- **窗口按钮**：按钮可以放在左边或右边；macOS 可以改用系统红绿灯，Dock 菜单也能控制播放。从托盘恢复、最小化时，任务栏缩略图的播放按钮都会照常更新。
- **歌词样式新选项**：莫奈可以左右镜像、关闭肖像、自定义描述；时计的表盘可以倾斜、分层，并新增轮心视角；回环可以调位置并沿圆环显示翻译。
- **液态玻璃补全**：导航、搜索、底部播放条、正在播放卡、登录按钮、平台切换器和播放器返回键的液态玻璃都回来了。搜索框不再跟着输入流动，导航条保持静止。
- **玻璃边缘与可读性**：修掉了高缩放屏幕（如 125%）上玻璃描边的虚线感，以及圆角处的锯齿；深色主题配浅色壁纸时，导航与搜索文字不再是浅色压浅色。
- **首次启动引导恢复正常**：0.8.0 的版本标记与实际版本不一致，导致升级后新功能介绍、播放入口选择和引导教程都不再出现。这一版修好了，并加了测试盯住版本号。
- **听歌报告与歌单打开方式回到命令面板**：这两组入口在同步时丢了，现在都补回来了。
- **远端遥控窗**：队列向上展开时卡片不再跑位，展开时的淡出补齐；关闭时保存的是卡片位置，下次打开不会再整体下移一个队列的高度。
- **AI 主题生成与歌词分词的运行时报错**：上游换了调用签名，旧参数会让这两条路径直接失败，已对齐。
- **macOS 快捷键提示**：中文与印尼语界面里写死的 Ctrl 改成跟随平台显示（macOS 显示 Cmd）。

更新检查使用本仓库 `ithtelab/Folia-Plain`，保留 GitHub 直连与第三方国内加速入口。macOS 和 Linux 包通过各自系统的云端构建与打包资源检查，尚未完成每种发行版及设备上的人工运行验证；Intel Mac 的 Spotify 原生播放受上游二进制支持限制。在线音乐与 AI 仍需按平台要求配置或登录。问题请反馈到[本项目仓库](https://github.com/ithtelab/Folia-Plain/issues)；上游项目：[folia-major](https://github.com/chthollyphile/folia-major)。
