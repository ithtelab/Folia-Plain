Folia Plain 0.8.0 接入汽水音乐，新增花火歌词样式和听歌报告，探索页也会先给你自己最近在听的东西。

## 下载

- **Windows 10/11 x64**：`Folia-Plain-Setup-0.8.0-x64.exe` 安装版，或 `Folia-Plain-0.8.0-windows-x64.zip` 免安装版。
- **macOS**：Apple Silicon 选择 `arm64.dmg` / `arm64.zip`，Intel 选择 `x64.dmg` / `x64.zip`。应用未作开发者签名与公证；请参阅[macOS 打开说明](https://github.com/ithtelab/Folia-Plain/blob/main/docs/desktop/macos-app-damaged.md)。
- **Linux x64**：按发行版选择 `.deb`、`.rpm`，或下载 `.tar.gz` 便携包。便携运行说明在 `resources/linux/README-LINUX.txt`。
- **Web 部署**：`Folia-Plain-0.8.0-web.zip` 包含静态网站、部署说明和 Nginx 示例，在线音乐及 AI 功能需要对应后端。不是桌面安装器，不直接双击 HTML 运行。
- `SHA256SUMS.txt` 用于校验附件；`.yml` 与 `.blockmap` 是桌面更新文件。

## 本版变化

- **汽水音乐可以听了**：桌面版新增汽水音乐，扫码登录后可搜索、播放、看歌词，读你喜欢的歌和歌单，也能进它的推荐页与场景电台。音频走应用自己的解密通道，不经过浏览器；主进程对请求方做了来源校验。
- **花火：一场跟着歌词放的烟花**：新的歌词样式，歌词落在明亮色块上，烟花与拼贴贴纸随字词绽开，画面一拍一拍往上抬。设置里可选画质档，集成显卡卡顿时切到均衡或省电，歌词与辉光仍是全分辨率。
- **听歌报告**：命令面板搜「听歌报告」，看最近三十天的歌曲数、收听次数、时长、一张收听日历和最常听的歌。只用应用本来就记着的数据，不额外上报；时长按「每次至少半首」计，界面上写的是「至少」。
- **探索页先放你自己的**：Bravais 拼贴墙的探索页在平台推荐前面加上「最近播放」和「再听一次」，来自你在这台机器上听过的歌，各平台一致。这两栏是进页面时的快照，听歌时不会一直重排。
- **遥控窗文字底衬更自然**：透明模式下文字后面的深色底衬原来是边界清楚的实心灰块，浅色网页上像一块污渍。现在改成渐变加更大的模糊，左缘渐入、底部渐隐，和封面衔接不再有硬边。
- **歌词时钟对得更准**：时间轴按歌词时钟高亮和跳转；暂停的音轨载入或跳转时读头落在真实位置，不再等按下播放才跳过去；试听片段的歌词先挪到片段自己的时钟上再交给过渡规划。
- **播放的几处竞态修掉了**：队列被整表改写后，等待中的播放、失败后的跳过与重试、私人 FM 补歌、舞台编辑、会话恢复与窗口交接都不再把它盖回去；私人 FM 在补歌等待期间队列被就地改写时照常补歌并走下一首；切换 FM 模式时请求期间的下一首落地不再把切换丢掉。
- **macOS 壁纸模式的点击不再误触台前调度**：开着台前调度时点壁纸上的控件会被当成点桌面把窗口收走。桌面图标隐藏时用一层覆盖整面壁纸的点击收集层；图标显示时需要辅助功能授权，没有授权就只盖控件并提示一次。
- **玻璃参数有了冻结基线**：材质的模糊、位移、色调曲线写进一处并加了测试，改任何一个都会让测试失败，避免再出现「只调个颜色」导致反复回退。

更新检查使用本仓库 `ithtelab/Folia-Plain`，保留 GitHub 直连与第三方国内加速入口。macOS 和 Linux 包通过各自系统的云端构建与打包资源检查，尚未完成每种发行版及设备上的人工运行验证；Intel Mac 的 Spotify 原生播放受上游二进制支持限制。汽水音乐需要登录你自己的账号，可听范围取决于该账号的权限。

桌面安装包包含音频处理程序、分析运行库及模型，体积较大。在线音乐与 AI 仍需按平台要求配置或登录。问题请反馈到[本项目仓库](https://github.com/ithtelab/Folia-Plain/issues)；上游项目：[folia-major](https://github.com/chthollyphile/folia-major)。
