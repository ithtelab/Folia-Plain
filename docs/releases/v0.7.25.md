Folia Plain 0.7.25 加入 Windows 渲染显卡选择与后台节流开关，修复重启后登录被误删的问题，并让首页导航条不再流动。

## 下载

- **Windows 10/11 x64**：`Folia-Plain-Setup-0.7.25-x64.exe` 安装版，或 `Folia-Plain-0.7.25-windows-x64.zip` 免安装版。
- **macOS**：Apple Silicon 选择 `arm64.dmg` / `arm64.zip`，Intel 选择 `x64.dmg` / `x64.zip`。应用未作开发者签名与公证；请参阅[macOS 打开说明](https://github.com/ithtelab/Folia-Plain/blob/main/docs/desktop/macos-app-damaged.md)。
- **Linux x64**：按发行版选择 `.deb`、`.rpm`，或下载 `.tar.gz` 便携包。便携运行说明在 `resources/linux/README-LINUX.txt`。
- **Web 部署**：`Folia-Plain-0.7.25-web.zip` 包含静态网站、部署说明和 Nginx 示例，在线音乐及 AI 功能需要对应后端。不是桌面安装器，不直接双击 HTML 运行。
- `SHA256SUMS.txt` 用于校验附件；`.yml` 与 `.blockmap` 是桌面更新文件。

## 本版变化

- **双显卡可以挑用哪张**：Windows“设置 → 性能与动效”新增“渲染显卡”，可选自动 / 高性能 / 省电。双显卡笔记本默认走核显，想用独显渲染时在这里指定，保存后重启生效。命令行开关与系统“图形设置”里的指定优先于这一项。
- **后台不再全速渲染**：性能页新增“后台节流”开关，默认关闭。打开后窗口最小化或被遮挡时交给系统节流，歌词动画停在当前画面，回来时接着走。壁纸模式、窗口置顶、视频导出和 OBS 浏览器源连着时自动让位。
- **重启后登录不再丢**：断网、服务器出错或这次读不出加密存储时，不再当成没人登录而删掉仍然有效的登录；只有平台明确说失效才清。QQ 桌面版会定时续期，退出、重启或崩溃前先把页面存储写盘。
- **首页导航条不再流动**：顶部标签胶囊保留玻璃质感与边缘高光，但去掉了流动的反射。这一条是读一眼就要看懂位置的控件，流动的高光只是干扰；底部播放条同样保持静止。

更新检查使用本仓库 `ithtelab/Folia-Plain`，保留 GitHub 直连与第三方国内加速入口。macOS 和 Linux 包通过各自系统的云端构建与打包资源检查，尚未完成每种发行版及设备上的人工运行验证；Intel Mac 的 Spotify 原生播放受上游二进制支持限制。

桌面安装包包含音频处理程序、分析运行库及模型，体积较大。在线音乐与 AI 仍需按平台要求配置或登录。问题请反馈到[本项目仓库](https://github.com/ithtelab/Folia-Plain/issues)；上游项目：[folia-major](https://github.com/chthollyphile/folia-major)。
